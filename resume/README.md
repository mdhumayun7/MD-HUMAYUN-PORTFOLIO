# Resume sources

LaTeX sources for the role-specific resumes served by the portfolio. Compile with `pdflatex` (twice), then copy the PDF into `public/`.

| Source | PDF in `public/` | Used for role |
| --- | --- | --- |
| `ml.tex` | `resume.pdf`, `resume-ml.pdf` | ML Engineer, Security & Research, default |
| `sde.tex` | `resume-sde.pdf` | Software Engineer |
| `embedded.tex` | `resume-embedded.pdf` | Embedded & Systems |

The role-to-file mapping lives in `src/data/roles.js`.
